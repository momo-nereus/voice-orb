# VOICE ORB

两个纯静态的声音小东西。零依赖、零构建、零后端 —— 一个 HTML 文件丢上去就能跑。

| 目录 | 是什么 |
|---|---|
| [`voice-orb/`](voice-orb/) | **音频可视化** —— 一颗会呼吸的球，跟着声音的形状变化 |
| [`voice-call/`](voice-call/) | **语音对话** —— 按一下说话，它回答你，球跟着声音动 |

两个都是单文件、无依赖，用的是浏览器原生的 Web API。不加载任何第三方库，不向任何服务器发送数据。

---

## voice-orb · 余音栖于此处

导入一段音频，或者让它听周围的环境声，球都会跟着动。

- **音频模式** —— 选本地文件播放，球跟着音乐变化。本地双击就能用。
- **麦克风模式** —— 球的形态跟着环境声实时变化。需要 HTTPS。

右上角 ⚙ 可以调：球体尺寸、模糊强度、呼吸幅度、音频灵敏度、光晕扩散、信号阻尼。

---

## voice-call · 语音通话

一个可以接自己模型的语音通话页：**说话 → 识别 → 请求你自己的接口 → 朗读回答**，球体全程跟着声音动。

### 界面

- **静音** —— 关掉麦克风，改用输入框打字；再点一次恢复说话
- **私密模式** —— 把环境的音量与音高特征一起交给模型（默认关闭）
- **扬声器** —— 关掉就只显示字幕，不朗读
- **挂断** —— 结束这一通；再点一次是干净的一段新对话
- **实时字幕** —— 你说的和它说的，都实时显示在球下面

### 怎么用

1. 点右上角 **⚙**
2. 填三样东西：
   - **API 地址** —— 任何 OpenAI 兼容的 `/chat/completions` 接口，例如 `https://api.deepseek.com/v1`
   - **API Key** —— 你自己的 key
   - **模型名** —— 例如 `deepseek-chat`
3. 保存，然后点中间那个圆形按钮开始说话

人设提示词留空就用一句默认的（回答简短、便于朗读）。想让它有性格，自己写。
### 关于 Key

Key 只保存在**你自己这台设备的浏览器 localStorage 里**，请求由浏览器直接发往你填的那个 API 地址，中间不经过任何其它服务器。公共电脑上用完记得点「清空对话」并清掉设置。

## 部署

都是静态页面，扔到任意静态托管即可：

**Netlify Drop** — 打开 `app.netlify.com/drop`，把文件夹拖进去，几秒后给你一个网址，不用注册也能先试。

**GitHub Pages** — 推到这个仓库 → Settings → Pages → Source 选 `main` / `root`。之后访问
`https://<你的用户名>.github.io/<仓库名>/voice-orb/` 和 `.../voice-call/`。

**Vercel / Cloudflare Pages** — 同理，连仓库或拖文件夹都行。

> ⚠️ **麦克风必须 HTTPS**。这是浏览器的安全策略：`getUserMedia` 和 `SpeechRecognition` 只在 https 或 localhost 下可用。本地双击打开 html 时麦克风一定失败，这不是页面坏了。
>
> ⚠️ GitHub Pages / Vercel 在中国大陆访问可能较慢或不稳定。

## 隐私

不采集、不上传、不统计、不联网读取任何东西。

- voice-orb 全程在本地解析音频
- voice-call 唯一的外部请求就是你填的那个 API 地址
- 两个页面都没有 cookies、没有埋点、没有第三方脚本

唯一需要说明的一点：语音识别走的是浏览器的 Web Speech API，它的处理方式由浏览器决定（Chrome 会把语音送去 Google 的服务做识别）。介意的话，直接用键盘打字就好，其它功能完全不受影响。
